# Ruihan Lin Personal Site

This repository contains a lightweight Astro site for a concise academic homepage.

## Scope of the first release

- Single-page academic homepage
- Short bio instead of a full CV dump
- Three selected papers only
- Lightweight teaching section
- Contact information

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static output will be generated in `dist/`.

## Deployment

GitHub Pages is configured through GitHub Actions. Any push to `main` will build and deploy the site.
